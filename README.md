# Ligacord

B2B-платформа подбора **бартерных** партнёров с AI-агентом. Пользователь описывает,
что компания готова отдать в обмен и что ищет; агент подбирает релевантных партнёров
из базы, обосновывает каждый выбор (включая честные риски) и генерирует готовое КП.

Заявка на **President AI Award (PAIA)**, IT Park Uzbekistan.

## Что делает AI (для конкурса)

1. **Подбор с рассуждением** — агент выбирает 3 партнёра **из реальной базы** (`lib/companies.js`),
   а не выдумывает их, и оценивает взаимную ценность и пересечение аудиторий.
2. **Критический слой** — по каждому мэтчу честный риск / что проверить.
3. **Генерация КП** — готовое коммерческое предложение под конкретную пару компаний,
   в выбранном тоне и на выбранном языке.
4. **Двуязычность** — узбекский + русский.

Ключ Anthropic хранится только на сервере (`/app/api/*`), фронтенд его не видит.

## Возможности

- **Регистрация и вход** по номеру телефона и паролю (bcrypt, сессия в httpOnly-cookie)
- **Онбординг** — данные компании, что даёт и что ищет; можно пропустить
- **Публичный каталог** бартер-объявлений с поиском и фильтром по категориям
- **AI-подбор** партнёров из реальной базы + генерация готового КП
- Контакты компаний видны только авторизованным

## Запуск локально

Нужен Postgres.

```bash
npm install
cp .env.example .env          # заполните DATABASE_URL и AUTH_SECRET
npx prisma migrate dev        # создать таблицы
npm run seed                  # 24 демо-компании в каталог (опционально)
npm run dev
```

Открыть http://localhost:3000

**Без `ANTHROPIC_API_KEY`** приложение работает в демо-режиме (заглушки вместо
живого AI) — интерфейс и каталог функционируют полностью. С ключом подбор и КП
генерируются реально через Claude.

## Стек

- Next.js (App Router) — UI + серверные API-роуты
- PostgreSQL + Prisma 7
- Anthropic Claude API (`claude-opus-5` по умолчанию; можно `claude-sonnet-5`)

## Деплой (Railway)

1. Deploy from GitHub repo → выбрать этот репозиторий
2. `+ New → Database → PostgreSQL` в том же проекте
3. В сервисе задать переменные:
   - `DATABASE_URL` = `${{ Postgres.DATABASE_URL }}`
   - `AUTH_SECRET` = случайная строка (см. `.env.example`)
   - `ANTHROPIC_API_KEY` = ключ Anthropic
4. `Settings → Networking → Generate Domain`

Миграции применяются автоматически при старте (`prisma migrate deploy`).
